\## 📌 Overview

This project is a SQL database design and querying assignment for \*\*Nairobi Academy\*\*, a secondary school in Nairobi. The objective is to build a complete relational database from scratch and perform data manipulation and analysis using SQL.



\---



\## 🏫 Scenario

You are the new database administrator for Nairobi Academy. Your task is to design, create, populate, and manage the school database, then write queries to extract meaningful insights.



\---



\## 🗄️ Database Schema

The database consists of three main tables:



\### 1. Students

Stores student information such as:

\- student ID

\- first name

\- last name

\- class/form

\- gender

\- city



\### 2. Subjects

Stores information about subjects offered at the school:

\- subject ID

\- subject name

\- department

\- credit hours



\### 3. Exam Results

Stores student exam performance:

\- result ID

\- student ID

\- subject ID

\- marks

\- exam date
